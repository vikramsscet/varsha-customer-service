# Varsha Customer Service

## Purpose

Backend microservice for Varsha Homemade (varsha-homemade.com), providing customer authentication, shopping carts, checkout, orders, payments, delivery tracking, and customer feedback.

## Technology Stack

- Runtime: Node.js
- Framework: Express.js
- Language: JavaScript (no TypeScript)
- Database: PostgreSQL
- API style: REST
- Authentication: Google OAuth 2.0 and JWT
- Configuration: environment variables (.env)

This project follows SDD. See [specs/README.md](specs/README.md) for the workflow.

Application implementation begins only after the relevant specifications have been reviewed and approved.
